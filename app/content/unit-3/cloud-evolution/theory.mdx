<Callout kind="definition" title="In one line">
Computing moved from one shared mainframe, to every company running its own servers, to renting from huge shared data centres, and now partly back towards the devices at the edge.
</Callout>

## Why study the history?

Cloud computing did not appear suddenly. Each step solved a problem left by the one before. Knowing the steps explains why today's cloud has virtual machines, containers and pay-per-use bills.

## What made the cloud possible

- **Fast, cheap internet:** customers can reach a distant data centre quickly.
- **<Term id="virtualization">Virtualization</Term>:** one physical server can run many separate <Term id="virtual-machine">virtual machines</Term>, controlled by a <Term id="hypervisor">hypervisor</Term>. A provider can share its servers safely between customers.
- **Cheap, standard hardware:** data centres are built from thousands of ordinary servers.
- **Web standards and open source:** browsers, HTTP and free software such as Linux made services easy to build and use.

A <Term id="container">container</Term> is much lighter than a virtual machine. <Term id="serverless">Serverless</Term> goes one step further: code runs only when a message arrives, which suits IoT devices that report now and then.

## Related ideas

- <Term id="utility-computing">Utility computing</Term>: paying for computing like a utility bill. The cloud made McCarthy's 1961 idea real.
- <Term id="grid-computing">Grid computing</Term>: many computers in different places working on one job. Cloud data centres instead keep thousands of computers in one place, run by one provider.

<Callout kind="example" title="Starting an IoT company in 2005 and in 2025">
In 2005, a Bengaluru startup building a smart water meter had to buy servers, rent space in a data centre and hire staff before its first customer. In 2025, the same team opens a cloud account, uses an IoT platform for its devices and pays a few hundred rupees a month while it has only a hundred meters. When it grows to a lakh of meters, the cloud grows with it.
</Callout>

## What changed for IoT

**Gains**

- Anyone can collect and store data from millions of devices without building a data centre.
- Serverless and containers make it cheap to process occasional sensor messages.
- Ready IoT platforms handle device identity, MQTT and rules.

**New challenges**

- Dependence on the internet and on one provider.
- Latency for fast control, which brought computing back to the edge.
- Data privacy, because data now leaves the building.
